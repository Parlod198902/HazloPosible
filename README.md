# Hazlo Posible 360°: Transformamos la vida de las personas en momentos felices 

**Hazlo Posible 360°** es una plataforma web diseñada para centralizar y optimizar la gestión de apoyos para las **Casas de la Fundación Infantil Ronald McDonald México**. El proyecto transforma procesos tradicionalmente dispersos en un ecosistema digital único, facilitando que la comunidad se involucre de manera inmediata a través de donaciones simbólicas y un sistema estructurado de voluntariado.

## El Desafío
Actualmente, existe una desconexión crítica: aunque miles de personas interactúan con la marca diariamente, no existen mecanismos inmediatos en el punto de venta que faciliten la participación inmediata en donaciones o voluntariado para las Casas de la Fundación Infantil Ronald McDonald México. Esto limita el aprovechamiento del interés solidario de los usuarios en el momento de compra y genera procesos fragmentados que suelen realizarse a través de canales externos.

## Nuestra Solución: Un Ecosistema Centralizado
**Hazlo Posible 360°** es una plataforma web diseñada para centralizar la gestión de donaciones y el pre-registro de voluntariado para las Casas de la Fundación Infantil Ronald McDonald México, facilitando la participación directa de la comunidad en un entorno digital accesible. La plataforma actúa como un nodo central que conecta el deseo de ayudar con la necesidad operativa de las Casas, operando bajo dos ejes principales:

### 1. Donación Mediante Menús Simbólicos
Convertimos la donación en una experiencia familiar y tangible:
* **Aportaciones Definidas:** El usuario selecciona "menús" que representan montos económicos específicos destinados al sustento de las familias.
* **Transparencia Total:** Cada transacción genera una confirmación digital inmediata, asegurando al donante que su apoyo llegará directamente a la Fundación.

### 2. Prerregistro de Voluntariado Profesional
Digitalizamos la captación de talento humano para las Casas:
* **Selección por Actividad:** Los usuarios eligen áreas específicas como comedor, limpieza o acompañamiento.
* **Control de Disponibilidad:** Calendario integrado para que el voluntario proponga días y horarios exactos.
* **Seguridad Garantizada:** El sistema genera un prerregistro que permite a los administradores realizar entrevistas previas, asegurando la integridad de los niños y adolescentes beneficiarios.

## Funcionalidades Clave
* **Centralización Total:** La plataforma transforma un proceso fragmentado en un sistema centralizado y digital para una gestión más eficiente.
* **Panel de Gestión:** Proporciona una interfaz para que el personal administrativo pueda monitorear donaciones y coordinar al voluntariado.
* **Reducción de Intermediarios:** Reduce la dependencia de terceros en la gestión de donaciones y mejora la captación de voluntariado operativo dentro de las Casas.

## Impacto Esperado
A diferencia de los métodos tradicionales, **Hazlo Posible 360°** elimina la fricción en el proceso de ayuda. Al integrar la captación de fondos y el reclutamiento de voluntarios en una sola herramienta, permitimos que la Fundación Infantil Ronald McDonald México se enfoque en lo más importante: **mejorar el bienestar de las familias durante el tratamiento médico de sus hijos.**

## Justificación Tecnológica (Stack)
Construido con una arquitectura **Fullstack** moderna para garantizar escalabilidad y seguridad:

* **Frontend (React + Vite + Tailwind CSS):** Una Single Page Application (SPA) que ofrece una navegación fluida, responsiva y sin fricciones.
* **Backend (Node.js + Express):** API REST robusta que centraliza la lógica de negocio y valida la integridad de cada solicitud.
* **Procesamiento de Pagos (Stripe):** Integración segura bajo el estándar PCI DSS Nivel 1, utilizando protocolos HTTPS y autenticación reforzada (3D Secure 2).
* **Nube y Datos (Firebase):** Solución BaaS para almacenamiento flexible en JSON y sincronización instantánea con el panel administrativo.
